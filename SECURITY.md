# Security policy

## Supported versions

This is a personal/community project — only `main` is supported. If you found something on a stale fork, please update first.

## Reporting a vulnerability

Please **do not open a public issue** for anything that could be exploited (token leakage, SQL injection in a command, anything that can crash a host's bot, etc.).

Instead:

1. Open a [private security advisory](https://github.com/Armaan-Khehra/blvck0ut/security/advisories/new) on this repo, or
2. DM `@Armaan-Khehra` on GitHub with the details.

I'll acknowledge within a few days, work on a fix, and credit you in the release notes once it's patched (unless you prefer to stay anonymous).

## Out of scope

- Anything that requires a malicious server admin to be exploitable (admins can already do whatever they want on their own server).
- Rate-limit / spam concerns — please open a normal issue with the `enhancement` label.

Thanks for keeping the project safe.
